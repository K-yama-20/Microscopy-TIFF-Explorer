# Manual browser test TIFFs

These files are generated by:

```powershell
cd backend
.venv\Scripts\python scripts\generate_manual_test_tiffs.py
```

Each valid image contains a visible label or pattern so a selector change can
be confirmed by eye. Downloaded PNGs should match the current preview.

| File | Expected browser behavior |
| --- | --- |
| `01_grayscale_uint8_yx.tif` | Grayscale preview; no T/Z/C selector; download name ends in `_T000_Z000_C000.png`. |
| `02_zstack_uint16_zyx.ome.tif` | Z selector with 4 planes labeled Z0–Z3; 16-bit source is normalized to an 8-bit preview/export. |
| `03_channels_uint8_cyx.ome.tif` | Channel selector with C0–C2 and visibly different planes. |
| `04_full_uint16_tzcyx.ome.tif` | Time 0–1, Z 0–2, Channel 0–1; every combination has its T/Z/C label. |
| `05_rgb_uint8_yxs_interleaved.ome.tif` | RGB composite plus Red/Green/Blue grayscale component choices. |
| `06_rgb_uint16_syx_planar.ome.tif` | Planar 16-bit RGB; composite stays color and isolated components are grayscale. |
| `07_channels_rgb_uint8_cyxs.ome.tif` | Both microscopy Channel and Color component selectors; changing either must affect the image independently. |
| `08_constant_uint16_yx.tiff` | Valid uniform 16-bit image; preview/export should be uniformly black without an error. |
| `09_lzw_uint8_yx.tif` | LZW-compressed grayscale TIFF; should behave like an ordinary YX image. |
| `90_unsupported_float32_yx.tif` | Upload should fail with the supported-dtype message. |
| `91_unsupported_rgba_uint8_yxs.tif` | Upload should fail because RGBA is outside MVP v1. |

For RGB downloads, verify the suffixes `_RGB.png`, `_R.png`, `_G.png`, and
`_B.png`. For `07_channels_rgb_uint8_cyxs.ome.tif`, verify that the `C000` or
`C001` segment changes with the microscopy Channel while the RGB suffix changes
only with the Color component.
